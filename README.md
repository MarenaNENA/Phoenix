# 🔥 Phoenix

> **Giving pre-owned items a second chance.**

Phoenix is a sustainability-focused mobile marketplace that gives pre-owned items a second chance through **donation or affordable resale**. The project aims to reduce waste, encourage reuse, and make it easier for people to give unwanted items a new life.

## 📱 About the Project

Phoenix was developed as our **Graduation Project 1**, inspired by the idea of renewal represented by the Phoenix — rising from the ashes and beginning a new life.

The application connects users through a marketplace where they can donate or resell pre-owned items, while providing tools that make discovering, communicating, and exchanging items easier.

## ✨ Features

* 🔐 **User Authentication**
* 🛍️ **Donation & Resale Marketplace**
* 💬 **Real-time Chat Between Users**
